# ========================================
# AI FILTERING CRITERIA
# ========================================

# The AI half of the filter is no longer written down here. It lives in Rally
# Studio, under News > Filters, as a set of filter rules that can be versioned
# and deployed — see "Changing what counts as good news" in README.md, and
# editorial_filter.py for the code that reads it.
#
# In short: the model is given a job (the Prompt), a person to be while it does
# it (the Personality), and a list of statements about the story (the Scoring
# Questions). It rates every statement from 1 (disagree completely) to 10 (agree
# completely) in that person's voice, and the AVERAGE of those answers is the
# story's score. A story qualifies when the average reaches the cutoff and fewer
# than `veto_count` answers came back as a 1 — and nothing below 5.0 is ever
# published, whatever the settings say. A run then takes every qualifying story
# at `strong_score` or above, however many there are, and only reaches down to
# the cutoff to fill a shortfall. A run that qualifies nothing publishes nothing
# and is marked in Studio as a blank scrape.
#
#   python editorial_filter.py --show   # the exact prompt a run would use
#
# Nothing in this file is read by the scraper. The keyword lists above are kept
# as a record of the pre-AI filter and as a starting point for anyone tuning the
# prompt; edit the deployed filter version in Studio, not this.
